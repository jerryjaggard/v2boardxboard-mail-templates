## 📬 Email Types

Each theme includes these 5 essential email templates:

1. **notify.blade.php** - General notifications and announcements
2. **verify.blade.php** - Email verification with code
3. **mailLogin.blade.php** - Login notification alerts
4. **remindExpire.blade.php** - Subscription expiry reminders
5. **remindTraffic.blade.php** - Traffic usage warnings

## 🚀 Installation

1. Choose your preferred theme folder (e.g., `modern`, `premium`, `aurora`)
2. Copy all `.blade.php` files from that folder
3. Paste them into your XBoard/V2Board installation at: `resources/views/mail/`
4. Your email templates are now active!

## 📝 Template Variables

All templates support these Blade variables:

- `{{ $name }}` - Your application/service name
- `{{ $subject }}` - Email subject line
- `{{ $content }}` - Main email content
- `{{ $url }}` - Call-to-action URL
- `{{ $code }}` - Verification code (verify template only)
